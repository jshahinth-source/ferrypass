# KFC_DIGITAL_FERRY_BOARDING_PASS (KDFBP)
KFC Digital Ferry Pass System 2026


This WebApp system has developed by Shahinth Jeewaratnam in 2026 for the purpose of  travel pass for the Kooddoo Fisheries Corporation staff (MIFCO Maldives) to travel officially from KFC to other Islands. 

This system can
1. Audit user's travel data
2. Give Digital Experience and save paper waste
3. Live boarding update
4. Role Based Accessing System (RBAS)
5. Live Notice Board (Staff/Ferry shootouts)
6. Live user travel pass tracking
7. Cloud Based data retrieving system (User data will be fetched automatically from cloud when the admin/supervisor/Staff  try to apple from Issue pass section)
8. Secured by Google Firebase/Firestore (Powered by Google PLC)
9. Best user experience to use from both PC/Mobile Devices
